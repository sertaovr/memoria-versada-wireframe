# Memória Versada 2.0 - Wireframe

Protótipo navegável do acervo digital da produção autoral de São José do Egito.
Layout para laptop, em preto e branco, com quatro quadros em versos e sete telas.

## Publicação no GitHub Pages

1. Envie estes quatro arquivos diretamente para a raiz do repositório.
2. Abra Settings > Pages.
3. Em Source, selecione Deploy from a branch.
4. Selecione a branch main e a pasta /(root), depois Save.
5. Aguarde a publicação e abra o endereço informado em Visit site.

## Arquivos

- index.html: versão navegável, com estilos e elementos visuais incorporados.
- memoria-versada-wireframe.pdf: vistas horizontais para apresentação.
- .nojekyll: indica publicação de arquivos estáticos.
- README.md: descrição do protótipo.

Não é necessário instalar dependências nem executar comandos de compilação.
Somente a navegação está ativa. Busca, filtros, formulários e mídias são representações.
Nenhum dado ou arquivo é enviado pelo protótipo.
